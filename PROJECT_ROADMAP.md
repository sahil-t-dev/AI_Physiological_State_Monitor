# PBL Project Roadmap

## Completed
- Python environment
- Physiological demo dataset
- Data cleaning
- Time-series features
- Personalized baseline
- Isolation Forest anomaly detection
- Streamlit dashboard
- Dashboard tabs and anomaly severity

## Next
1. Select and document a suitable public physiological dataset.
2. Perform exploratory data analysis (EDA).
3. Compare Isolation Forest with a statistical baseline method and/or another anomaly detector.
4. Add evaluation metrics appropriate for anomaly detection.
5. Add model-result charts to the report.
6. Finalize architecture, methodology, DFD/flowchart.
7. Prepare PBL report, PPT and viva questions.

## Scope
The system identifies deviations from a personal physiological pattern. It is not a clinical diagnostic system.
